# Double-Barrel Films: link page demo

A temporary demo of the QR-code link page for Double-Barrel Films, hosted on GitHub Pages.

- **Live demo:** https://zlatish.github.io/Double-Barrel-Films-QR-Code/
- **Demo QR code:** `demo-qr/demo-qr.png`. It opens the demo URL above and is for showing the client only. **Don't print it.**

The final page will be hosted on the client's own Wix site at `https://www.doublebarrelfilms.co.uk/links`, with its own QR code. This repository is only for the demo, and the page is set to `noindex` so search engines don't list it.
